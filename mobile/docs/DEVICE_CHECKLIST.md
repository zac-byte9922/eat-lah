# 手机验收步骤（待真机执行）

本清单不代表已完成真机测试。云环境已运行的检查见 `VALIDATION.md`。

1. 全新安装/清除测试 App 数据后启动，跳转首次设置；无效邮编不能继续，预算、热量、厨具、过敏保存后生效。
2. 在小屏 Android 和带安全区的 iPhone 上检查文字换行、键盘遮挡、底栏、安全区、系统字体放大和 TalkBack/VoiceOver。
3. 早餐/午餐/晚餐 → 我想做点 → 五种口味 → 单卡；左滑换菜、右滑保留，纵向滚动不误触，撤销跳过返回上一张。
4. 加/跳过配菜和小食；螺蛳粉加料改变购物需求。收藏卡片并在“我的”查看。
5. 今天省点事 → 在家/外食/外卖；外食打卡不增加或扣除库存。
6. 购物清单中填写包装，例如需 80g、每包 50g，建议 2 包；只勾选实际买到的，输入实际包数。未买到的维持缺货。
7. 只确认购买、不确认安全状态时，库存存在但不能用于完成；到厨房核对后才可用。填写过去有效期，确保不可用。
8. 逐步看完做法后完成；核对日志和库存用量。连续点完成不重复扣减；撤销恢复原批次，常备调料不逐次扣。
9. 生成 3 天和 7 天菜单，检查每餐、共享清单和已有库存抵扣。已完成餐次不被覆盖。
10. 关闭并重新打开 App，资料、菜单、收藏、历史仍在；后台恢复后重新核对日期、库存状态与新加坡日期边界。
11. 飞行模式下使用本地功能；分享备份、系统返回手势、Android 硬件返回均不崩溃。
12. 记录机型、OS、Expo Go/开发包版本、结果与截图。测试库存应采用虚拟数据，不将演示烹饪步骤作为食品安全审核结论。
